# Changelog

## [1.0.0]

- Forked from the l10n.dev AI Translator; the l10n.dev backend is replaced by direct calls to Claude, Gemini, OpenAI and DeepSeek
- Settings: AI provider selection, plus a model and an API key per provider; "Fetch models" lists the models available for your key
- Long notes are split into chunks and translated in parallel
- Gemini 3/4: thinking is set to `low` for faster translations
- Language picker uses a built-in list instead of a remote search
